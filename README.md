# VTT Security Awareness landing page

This is a static awareness landing page for an authorised internal training exercise.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish and use the URL shown in Settings → Pages.

## Important tracking limitation
GitHub Pages only hosts static files. This page does not identify visitors or record employee clicks. Do not add employee names, email addresses, passwords, MFA codes, or confidential company information to this public repository.

For individual click tracking, connect an approved private backend and use random employee-specific tokens. Keep the token-to-employee mapping in a private, access-controlled location, and obtain management approval before running the exercise.
